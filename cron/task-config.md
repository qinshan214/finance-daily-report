# 定时任务详细配置

## 任务基本信息

| 项目 | 值 |
|------|-----|
| 任务名称 | 每日财经日报推送 |
| 执行时间 | 每天 20:00（可调整） |
| 任务类型 | 周期性任务（cron） |
| cron 表达式 | `0 20 * * *` |
| 运行环境 | 云电脑 / 服务器 |

## 执行内容

### 1. 国家统计局数据采集
- **目标 URL**：https://www.stats.gov.cn/
- **采集内容**：
  - 当天新发布的宏观经济数据简述
  - 若无新发布，标注最近一期数据并说明
  - 近期发布预告（未来 2-4 周）
- **重点关注**：CPI、PPI、PMI、工业增加值、固定资产投资、社会消费品零售总额、进出口、工业企业利润、GDP 等

### 2. A股行情与资金流向（多源降级）

**主源：同花顺行情中心**
- URL：https://q.10jqka.com.cn/
- 内容：主要指数、涨跌分布、涨跌停数量

**备用1：东方财富网**
- URL：https://www.eastmoney.com/
- 内容：指数、板块变化、资金流向、龙虎榜

**备用2：新浪财经股票页**
- URL：https://finance.sina.com.cn/stock/
- 内容：行业板块涨幅、资金净流入、概念板块

**采集内容清单**：
- 2.1 主要指数表现（上证、深证、创业板、科创50、沪深300、北证50）
- 2.2 板块变化（领涨/领跌概念板块、热点题材）
- 2.3 大额资金流向（行业/个股主力资金、ETF资金、龙虎榜、融资融券）
- 2.4 全球市场动态（美股、美债、黄金、汇率、原油、中概股）
- 2.5 A股与行业动态（IPO、定增、并购、机构观点、产业趋势）

**降级策略**：
1. 按优先级依次尝试，第一个成功的即为主数据源
2. 其余成功的作为补充数据源
3. 全部失败时标注"A股行情数据全部抓取失败"，禁止编造
4. 部分成功时标注实际使用的数据源和失败项

### 3. 新浪财经新闻采集
- **目标 URL**：https://finance.sina.com.cn/
- **采集内容**：
  - 3.1 国际局势（地缘政治、军事冲突、国际关系）
  - 3.2 宏观政策（政策文件、监管动态、经济数据）
  - 3.3 公司动态（上市公司公告、新品发布、业绩、并购）
  - 3.4 其他新闻（文娱、体育、社会等泛财经事件）

### 4. 生成飞书文档
- **文档标题格式**：财经日报-YYYY年MM月DD日
- **文档结构**：详见 `../docs/report-structure.md`
- **文档权限**：可设置为"互联网获得链接的任何人可查看"

### 5. 输出与推送（可选）
- 将飞书文档链接输出到对话窗口
- （可选）通过飞书消息推送到指定用户，包含核心摘要和文档链接

## 失败处理规则

1. **单源失败**：在日报"数据采集说明"中标注该源抓取失败，使用其他源的数据补充
2. **全部失败**：标注"该板块数据全部抓取失败"，不编造任何数据
3. **部分数据缺失**：明确标注哪些子项缺失，不推测、不补全
4. **网络超时**：重试一次，仍失败则标注失败

## 数据真实性原则

- **禁止编造**：任何数据必须来自实际抓取，不得推测或虚构
- **明确标注**：失败项、缺失项、估算项必须明确标注
- **来源可溯**：每个数据板块标注数据来源网站
- **时间明确**：标注数据采集时间和数据对应的交易日

## 执行时间建议

| 场景 | 推荐时间 | 说明 |
|------|----------|------|
| 默认 | 每天 20:00 | 晚间回顾，数据完整 |
| 交易日即时 | 每个交易日 15:30 | A股收盘后立即生成 |
| 早间预览 | 每天 08:00 | 前一交易日回顾 + 当日展望 |

> A股交易时间 9:30—15:00，建议执行时间在 15:30 之后以确保收盘数据完整。
