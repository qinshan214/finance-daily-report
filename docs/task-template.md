# AI 助手任务指令模板

> 将下方完整指令复制后发送给 AI 助手，即可创建每日财经日报定时任务。
> 使用前请替换 `{{open_id}}` 为实际的飞书用户 open_id。

---

## 完整创建指令

```
创建定时任务，执行时间每天20:00。

任务工作内容：
1、访问国家统计局官网 https://www.stats.gov.cn/ ，抓取当天新发布信息，做简短文字简述；

2、获取A股行情与资金流向数据，采用多源降级策略，按以下优先级依次尝试，第一个成功的数据源即为主数据源，其余作为补充：
   - 主源：同花顺行情中心 https://q.10jqka.com.cn/ （获取主要指数、涨跌分布、涨跌停数据）
   - 备用1：东方财富网 https://www.eastmoney.com/ （获取指数、板块变化、资金流向、龙虎榜）
   - 备用2：新浪财经股票页 https://finance.sina.com.cn/stock/ （获取行业板块涨幅、资金净流入、概念板块）
   - 需获取的数据包括：上证指数、深证成指、创业板指、科创50等主要指数表现，领涨/领跌概念板块变化情况，行业/个股主力资金、ETF资金等大额资金流向变化，以及美债、美股、黄金、汇率等全球市场动态和两融、REITs、机构观点等A股与行业动态；
   - 若所有数据源均抓取失败，在日报中标注「A股行情数据全部抓取失败」，禁止编造数据；若部分成功，标注实际使用的数据源；

3、访问新浪财经 https://finance.sina.com.cn/，整理当日重要新闻事件简述，涵盖国际局势（地缘政治、军事冲突、国际关系）、宏观政策（政策文件、监管动态、经济数据）、公司动态（上市公司公告、新品发布、业绩等）、其他新闻（文娱、体育、社会等泛财经事件）；

4、把以上三部分内容整理完整，生成飞书文档，文档标题格式：财经日报-YYYY年MM月DD日。文档结构包含：
   - 板块一：国家统计局最新发布（当日新发布数据、近期发布预告）
   - 板块二：A股行情与资金流向（2.1主要指数表现、2.2板块变化、2.3大额资金流向、2.4全球市场动态、2.5A股与行业动态）
   - 板块三：当日重要财经新闻（3.1国际局势、3.2宏观政策、3.3公司动态、3.4其他新闻）
   - 板块四：数据采集说明（采集时间、数据来源、失败标注说明）；

5、仅将飞书文档链接输出到当前对话窗口，不输出完整日报内容；

6、（可选）将日报核心摘要和飞书文档链接通过飞书消息推送到用户本人账号（open_id: {{open_id}}），使用 lark-cli im +messages-send --user-id {{open_id}} --as user 发送，消息格式使用 --markdown，包含三大板块核心数据摘要和文档链接。

备注：网站全部使用公开网页，不需要登录。某网站抓取失败则在日报中标注实际使用的数据源和失败项，禁止编造数据。
```

---

## 参数替换说明

| 参数 | 说明 | 获取方式 |
|------|------|----------|
| `{{open_id}}` | 接收飞书消息推送的用户 open_id | 让目标用户对 AI 说「查看我的飞书账号信息」，或执行 `lark-cli contact +get-user --as user` 获取 |
| 执行时间 `每天20:00` | 可按需调整 | 直接修改指令中的时间描述，如 `每天18:30`、`每个交易日15:30` |

## 飞书推送消息格式（示例）

```markdown
## 📊 财经日报-YYYY年MM月DD日

**一、国家统计局**
- 核心数据1
- 核心数据2

**二、A股行情（MM月DD日收盘）**
- 上证指数 XXXX.XX，+X.XX%
- 主力资金净流入XXX亿元
- 领涨板块：XXX

**三、重要新闻**
- 国际局势：XXX
- 宏观政策：XXX
- 公司动态：XXX

📄 完整日报：{{飞书文档链接}}
```

## 使用步骤

1. **获取目标用户 open_id**：用目标账号登录飞书后，对 AI 说「帮我查一下我的飞书 open_id」
2. **替换模板参数**：将 `{{open_id}}` 替换为实际值（如不需要飞书消息推送，可删除第6步）
3. **发送创建指令**：将完整的任务配置段落复制发给 AI 助手
4. **确认创建成功**：AI 会返回任务名称、执行时间、首次触发时间
5. **（可选）测试运行**：对 AI 说「现在执行测试，以现在时间点获取数据并生成文档」，验证全流程

## 注意事项

- 三个数据源均为公开网页，**无需登录**
- 同花顺主站 `www.10jqka.com.cn` 可能被安全策略拦截，使用行情中心子域名 `q.10jqka.com.cn` 可正常访问
- A股交易时间为 9:30—15:00，建议执行时间设在 **15:30 之后**，确保收盘数据完整
- 若遇周末/节假日，同花顺和新浪财经仍可抓取，但行情数据为最近一个交易日收盘数据
- **禁止编造数据**：某网站抓取失败时必须在日报中明确标注「该网站抓取失败」
- 飞书消息推送使用用户本人身份发送（`--as user`），接收人为自己，不会打扰他人
