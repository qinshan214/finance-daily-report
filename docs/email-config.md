# 邮件推送配置说明

本项目支持通过邮件推送每日财经日报，目前已测试通过 QQ 邮箱 SMTP 服务。

## 支持的邮箱服务商

| 邮箱服务商 | SMTP 服务器 | 端口 | 加密方式 | 状态 |
|-----------|------------|------|---------|------|
| QQ 邮箱 | smtp.qq.com | 465 | SSL | ✅ 已测试通过 |
| 163 邮箱 | smtp.163.com | 465 | SSL | 理论支持 |
| Gmail | smtp.gmail.com | 465 | SSL | 需应用专用密码 |
|  Outlook | smtp.office365.com | 587 | TLS | 理论支持 |

## 脚本说明

邮件推送脚本：`scripts/send_email.py`

### 功能特性
- 支持 QQ 邮箱等 SMTP 服务发送邮件
- 自动生成 HTML 格式精美邮件
- 支持传入三大板块核心摘要（国家统计局、A股行情、财经新闻）
- 支持传入飞书文档链接
- 通过环境变量或命令行参数配置邮箱凭证

### 使用方式

```bash
# 方式一：通过环境变量设置凭证（推荐）
export SMTP_USER="你的邮箱@qq.com"
export SMTP_PASSWORD="你的邮箱授权码"

python3 scripts/send_email.py \
  --to "收件人邮箱@example.com" \
  --doc-url "https://你的飞书文档链接" \
  --date "2026年08月28日" \
  --summary-stats "2025年经济发展新动能指数增长12.5%
1—7月份规上工业企业利润增长17.6%" \
  --summary-market "上证指数 3956.57，+1.13%
创业板指 3473.35，+1.71%
主力资金净流入超400亿元" \
  --summary-news "美联储官员称若通胀未回落将支持加息
伊朗否认刺杀特朗普幼子"

# 方式二：通过命令行参数设置凭证
python3 scripts/send_email.py \
  --user "你的邮箱@qq.com" \
  --password "你的邮箱授权码" \
  --to "收件人邮箱@example.com" \
  --doc-url "https://你的飞书文档链接" \
  --date "2026年08月28日"
```

### 命令行参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--to` | 是 | 收件人邮箱地址 |
| `--user` | 否* | 发件人邮箱地址（*可通过 SMTP_USER 环境变量设置） |
| `--password` | 否* | 发件人邮箱授权码（*可通过 SMTP_PASSWORD 环境变量设置） |
| `--host` | 否 | SMTP 服务器地址（默认 smtp.qq.com） |
| `--port` | 否 | SMTP 端口（默认 465） |
| `--doc-url` | 否 | 飞书文档链接 |
| `--date` | 否 | 日报日期（默认当天，格式：YYYY年MM月DD日） |
| `--summary-stats` | 否 | 国家统计局板块摘要（多行文本，每行一条） |
| `--summary-market` | 否 | A股行情板块摘要（多行文本，每行一条） |
| `--summary-news` | 否 | 财经新闻板块摘要（多行文本，每行一条） |

### 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `SMTP_HOST` | SMTP 服务器地址 | smtp.qq.com |
| `SMTP_PORT` | SMTP 端口 | 465 |
| `SMTP_USER` | 发件人邮箱地址 | 无 |
| `SMTP_PASSWORD` | 发件人邮箱授权码 | 无 |

## QQ 邮箱配置步骤

### 1. 开启 SMTP 服务

1. 登录 QQ 邮箱：https://mail.qq.com
2. 点击顶部「设置」→「账户」
3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
4. 开启「IMAP/SMTP服务」（如果未开启）
5. 点击「生成授权码」
6. 按提示用绑定手机发送短信验证
7. 复制生成的 **16 位授权码**（格式类似 `abcdefghijklmnop`）

### 2. 配置环境变量

```bash
export SMTP_USER="你的QQ号@qq.com"
export SMTP_PASSWORD="你的16位授权码"
```

### 3. 测试发送

```bash
python3 scripts/send_email.py \
  --to "你的QQ号@qq.com" \
  --doc-url "https://example.com" \
  --date "2026年08月28日" \
  --summary-stats "测试数据1
测试数据2" \
  --summary-market "上证指数 3000.00，+1.00%" \
  --summary-news "测试新闻"
```

## 安全注意事项

1. **授权码不是登录密码**：QQ 邮箱的 SMTP 授权码是独立于登录密码的，专门用于第三方客户端登录
2. **不要提交到公开仓库**：邮箱授权码是敏感信息，不要硬编码在脚本中或提交到 Git 仓库
3. **使用环境变量**：推荐通过环境变量 `SMTP_PASSWORD` 传递授权码
4. **定期更换授权码**：如果怀疑授权码泄露，可在 QQ 邮箱设置中删除并重新生成
5. **本仓库不包含任何真实凭证**：所有示例均使用占位符

## 常见问题

### Q: 发送失败，提示 "From header is missing or invalid"
A: QQ 邮箱对 From 头格式要求严格，确保 `msg['From']` 直接使用邮箱地址，不要加中文名称或复杂编码。

### Q: 发送失败，提示认证错误
A: 检查以下几点：
- 邮箱地址是否正确
- 授权码是否正确（不是登录密码）
- SMTP 服务是否已开启
- 授权码是否已过期或被删除

### Q: 邮件被识别为垃圾邮件
A: 可以尝试以下方法：
- 在收件人邮箱中将发件人添加为联系人
- 避免使用过于营销化的标题和内容
- 确保邮件内容完整、格式规范

### Q: 如何使用其他邮箱服务商
A: 修改 `--host` 和 `--port` 参数，或设置 `SMTP_HOST` 和 `SMTP_PORT` 环境变量。不同服务商的授权码获取方式类似，均需在邮箱设置中开启 SMTP 服务并生成授权码/应用专用密码。

## 邮件内容预览

邮件采用 HTML 格式，包含以下部分：
- 顶部渐变标题栏（日报标题 + 日期）
- 三大板块核心摘要（国家统计局、A股行情、财经新闻）
- 飞书文档链接按钮
- 底部页脚（数据来源说明）

样式采用响应式设计，在手机和电脑端均可正常显示。
