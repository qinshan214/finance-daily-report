# 每日财经日报 - 腾讯云函数部署指南

## 功能说明

本云函数实现每日财经日报的自动生成和推送，支持：
- ✅ 自动采集财经数据（国家统计局、腾讯财经、新浪财经）
- ✅ AI增强分析（AI优先，失败自动降级为纯脚本版）
- ✅ 自动创建飞书文档（设置权限+添加协作者）
- ✅ 邮件推送通知
- ✅ 定时触发（每天20:00）

## 部署步骤

### 第一步：准备代码包

1. 将 `cloud-function` 目录下的所有文件打包成 ZIP 文件
2. 确保目录结构如下：
   ```
   ├── main.py              # 云函数入口
   ├── requirements.txt     # 依赖包
   └── scripts/             # 业务脚本
       ├── collect_data.py
       ├── generate_report.py
       ├── ai_enhance_report.py
       ├── create_feishu_doc.py
       └── send_email.py
   ```

### 第二步：创建云函数

1. 登录[腾讯云函数控制台](https://console.cloud.tencent.com/scf)
2. 点击"新建" → "从头开始"
3. 填写基本信息：
   - **函数名称**：`finance-daily-report`
   - **地域**：选择国内地域（如广州、上海、北京）
   - **运行环境**：Python 3.10
   - **函数类型**：事件函数
   - **提交方法**：本地上传ZIP包
4. 上传第一步准备的ZIP包
5. 点击"完成"

### 第三步：配置环境变量

在云函数详情页 → "函数配置" → "环境变量"中添加以下变量：

#### 必选配置（飞书）

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `FEISHU_APP_ID` | 飞书应用App ID | `cli_xxxxxxxx` |
| `FEISHU_APP_SECRET` | 飞书应用App Secret | `xxxxxxxx` |
| `FEISHU_DOC_PERMISSION` | 文档权限 | `tenant_readable` |
| `FEISHU_DOC_COLLABORATOR_ID` | 协作者ID | `d1542736` |
| `FEISHU_DOC_COLLABORATOR_TYPE` | 协作者类型 | `userid` |
| `FEISHU_DOC_COLLABORATOR_PERM` | 协作者权限 | `full_access` |

#### 必选配置（邮件）

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `SMTP_SERVER` | SMTP服务器 | `smtp.qq.com` |
| `SMTP_PORT` | SMTP端口 | `465` |
| `SMTP_USER` | 发件人邮箱 | `xxx@qq.com` |
| `SMTP_PASSWORD` | 邮箱授权码 | `xxxxxxxx` |
| `MAIL_TO` | 收件人邮箱 | `xxx@qq.com` |

#### 可选配置（AI增强，不配置则使用纯脚本版）

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `DOUBAO_API_KEY` | 豆包API密钥 | `ark-xxxxxxxx` |
| `DOUBAO_API_URL` | 豆包API地址 | `https://ark.cn-beijing.volces.com/api/v3/chat/completions` |
| `DOUBAO_MODEL` | 豆包模型/接入点ID | `ep-xxxxxxxx` |

### 第四步：配置函数超时和内存

在"函数配置"中修改：
- **内存**：512MB（推荐）
- **执行超时时间**：300秒（AI调用可能需要较长时间）
- **初始化超时时间**：30秒

### 第五步：配置定时触发

1. 在云函数详情页 → "触发管理" → "创建触发器"
2. 填写触发器信息：
   - **触发方式**：定时触发
   - **触发器名称**：`daily-trigger`
   - **触发周期**：自定义
   - **Cron表达式**：`0 0 20 * * * *`（每天20:00执行）
3. 点击"提交"

> **Cron表达式说明**：腾讯云函数使用7位Cron表达式（秒 分 时 日 月 周 年）
> - 每天20:00：`0 0 20 * * * *`
> - 每天18:30：`0 30 18 * * * *`
> - 每周一9:00：`0 0 9 * * 1 *`

### 第六步：测试运行

1. 在云函数详情页 → "函数代码" → "测试"
2. 点击"测试"按钮
3. 查看执行日志，确认：
   - 数据采集成功
   - 日报生成成功
   - 飞书文档创建成功
   - 邮件发送成功

## 常见问题

### Q1: AI调用失败怎么办？
A: 系统会自动降级为纯脚本版，不影响日报推送。可以在日志中查看AI失败的原因。

### Q2: 飞书文档创建失败怎么办？
A: 检查飞书应用的权限配置，确保应用有"创建文档"、"设置权限"、"添加协作者"的权限。

### Q3: 邮件发送失败怎么办？
A: 检查SMTP配置，确保使用的是邮箱授权码而不是登录密码。QQ邮箱需要在设置中开启SMTP服务。

### Q4: 如何修改执行时间？
A: 在"触发管理"中修改Cron表达式。

### Q5: 如何查看执行日志？
A: 在云函数详情页 → "日志查询"中可以查看每次执行的详细日志。

## 技术支持
