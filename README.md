# 每日财经日报 · 自动化定时任务

基于 AI 助手的每日财经日报自动化生成工具，定时抓取国家统计局、同花顺、东方财富、新浪财经的公开数据，自动生成飞书文档。

## 功能特性

- **多源数据采集**：国家统计局（宏观经济数据）、同花顺/东方财富（A股行情与资金流向）、新浪财经（财经新闻）
- **多源降级策略**：主数据源被拦截时自动切换备用源，确保数据完整性
- **自动生成飞书文档**：按固定结构生成结构化财经日报
- **可配置推送**：支持飞书消息推送（可选）
- **数据真实性保障**：抓取失败明确标注，禁止编造数据

## 快速开始

### 方式一：通过 AI 助手创建定时任务（推荐）

1. 复制 `docs/task-template.md` 中的任务指令模板
2. 替换其中的 `{{open_id}}` 为你的飞书 open_id
3. 将完整指令发送给 AI 助手，告知"创建定时任务"
4. AI 助手会自动创建每天 20:00 执行的定时任务

### 方式二：使用 crontab（需自行实现抓取逻辑）

1. 参考 `cron/crontab.example` 配置定时执行时间
2. 根据 `scripts/run_daily_report.sh` 实现自己的抓取逻辑
3. 将脚本加入 crontab

## 日报内容结构

1. **板块一：国家统计局最新发布** — 当日新发布数据、近期发布预告
2. **板块二：A股行情与资金流向** — 主要指数、板块变化、资金流向、全球市场、行业动态
3. **板块三：当日重要财经新闻** — 国际局势、宏观政策、公司动态、其他新闻
4. **板块四：数据采集说明** — 采集时间、数据源、失败标注

详见 `docs/report-structure.md`。

## 配置说明

### 执行时间

默认每天 20:00 执行。A股交易时间为 9:30—15:00，建议执行时间设在 15:30 之后以确保收盘数据完整。

可调整为：
- 每个交易日 15:30（收盘后立即生成）
- 每天 18:30 / 20:00（晚间回顾）

### 飞书推送

- 生成飞书文档：默认开启
- 飞书消息推送：可选，需配置接收人 open_id
- 文档权限：可设置为"互联网获得链接的任何人可查看"或"仅组织内可查看"

## 注意事项

- 所有数据源均为公开网页，无需登录
- 某网站抓取失败时会在日报中明确标注，不会编造数据
- 周末/节假日行情数据为最近一个交易日收盘数据
- 本项目依赖 AI 助手的定时任务能力，非传统独立脚本
